# Changelog

All notable changes to ZZmazon will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-01-09

### Added
- Initial release of ZZmazon
- Complete implementation of Game of the Amazons rules
- 10x10 board with standard starting positions
- Full move validation (amazon moves and arrow shots)
- Game state management and turn handling
- Interactive command-line interface for human play
- AI vs AI demo mode
- Simple AI implementation (baseline bot)
- Console-based board visualization
- Move history tracking
- Game over detection
- Winner determination
- Setup.py for package installation
- Comprehensive test suite
- Bilingual documentation (English and Chinese)
- MIT License
- Examples directory with:
  - Botzone adapter example
  - Advanced AI with heuristics example
  - Example documentation
- Contributing guidelines
- Requirements specification

### Features
- Human vs Human play mode
- AI vs AI demo mode
- Interactive move input with validation
- Help command to show available moves
- Quit command for graceful exit
- Console display with coordinates
- Move notation: `from_row from_col to_row to_col arrow_row arrow_col`

### Technical Details
- Pure Python implementation (Python 3.7+)
- No external dependencies
- Object-oriented design
- Clean, readable, and maintainable code
- Comprehensive docstrings
- Type hints for better code clarity
- Modular architecture for easy extension

- Complete README with installation and usage instructions

- Development guide in CONTRIBUTING.md
- Example implementations
